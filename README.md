# Full-Stack E-Commerce Application
### [EN]

A full-stack e-commerce web application developed using Next.js and ASP.NET Core. This project focuses on building a modern online shopping platform with a scalable backend architecture, dynamic frontend, secure authentication, and online payment integration.

The project is being developed as a hands-on learning experience to strengthen my full-stack development skills and gain practical experience with modern web technologies.

## Features

* Product listing and product detail pages
* Shopping cart management
* User registration and authentication
* JWT-based authentication and authorization
* Order management
* Online payment integration with Stripe
* Responsive and modern user interface
* RESTful API architecture
* PostgreSQL database integration
* Server-side rendering with Next.js
* State management with Redux Toolkit

##  Project Architecture

The project follows a full-stack architecture consisting of:

* **Frontend:** Next.js application responsible for the user interface, routing, rendering, and state management.
* **Backend:** ASP.NET Core Web API responsible for business logic, authentication, validation, and data operations.
* **Database:** PostgreSQL for storing application data.
* **Payment System:** Stripe integration for online payment processing.


##  Getting Started

### Prerequisites

Make sure you have the following installed:

* Node.js
* .NET SDK
* PostgreSQL
* Git

### Clone the Repository

```bash
git clone https://github.com/muratguner1/Digital_ECommerce.git
```

### Backend Setup

```bash
cd backend
dotnet restore
dotnet run
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

### Environment Variables

Create the required environment variable files for the frontend and backend.

Example:

```env
DATABASE_CONNECTION_STRING=your_connection_string
JWT_KEY=your_jwt_secret
STRIPE_SECRET_KEY=your_stripe_secret
```

Do not commit real credentials or secret keys to GitHub.
